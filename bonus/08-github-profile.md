# Bonus 8 — GitHub Profile

> A strong GitHub profile = **consistent username**, filled **Edit profile** sidebar, **pinned repos**, and a **profile README** (`username/username`).

**Prerequisites:** [Lesson 7](../lessons/07-gitignore-and-project-organization.md)

---

## Consistent username

Use the **same handle** on GitHub, LinkedIn, X, and your portfolio. Search engines and recruiters connect your profiles more easily — one brand, not `johndoe` on one site and `john-dev-2024` on another.

---

## Edit profile

Profile → **Edit profile** — photo, full name, one-sentence bio, location, website, professional social links. Example bio:

```text
Learning Git & GitHub · Building web projects · Goobo Labs bootcamp
```

**Pin** up to 6 finished repos (e.g. `git-github-bootcamp`, `git-github-practice`, an OSS contribution).

---

## Contributions & activity overview

Your profile includes a **contribution graph** (green squares) — one square per day you contributed. Click **Contribution settings** on that section to toggle:

| **Setting** | **What it does** |
| ----------- | ---------------- |
| **Private contributions** | Counts activity on private repos on your graph (details stay private) |
| **Activity overview** | Shows orgs/repos you work in + a breakdown chart |

Turn **Activity overview** on. Below the graph you'll see:

- **Organizations and repos** you've contributed to (e.g. `@goobolabs`, bootcamp repos, OSS projects)
- A **breakdown chart** — typically **Commits**, **Code review**, **Issues**, **Pull requests**

### Contributions are more than commits

The green graph counts many activity types, not just `git commit`. For open source ([Bonus 3](03-open-source-contributing.md)), all of these build a strong profile:

| **Activity** | **Why it matters** |
| ------------ | ------------------ |
| **Issues** | Report bugs, ask questions, claim `good first issue` tasks |
| **Pull requests** | Ship fixes and features maintainers can merge |
| **Code review** | Comment on teammates' or OSS PRs — shows collaboration |
| **Commits** | Day-to-day work on branches and repos |

Someone with commits **and** issues, PRs, and reviews looks like a real collaborator — not just a solo coder. After the bootcamp, keep contributing to OSS repos: open an issue, submit a PR, review a classmate's PR. It all shows on your profile.

## Profile README

1. Create a **public** repo named exactly your username (`sharafdin/sharafdin`)
2. Add `README.md` — it renders above your pins

Keep it short: who you are, 2–3 project links, how to reach you.

You **can** add anything — tables, images, **animations**, custom styling. That is fine. What usually **does not** work is a README **taller than your profile sidebar** (the left column with photo and bio). Long animated profiles push pins down and make recruiters hunt for your repos. Shorter is better; animations sparingly if at all.

---

## Quality over quantity (skills)

Do **not** list every tool from every bootcamp or tutorial. List what you **use now** — one entry per layer:

| **Instead of…** | **Enough to list…** |
| --------------- | ------------------- |
| HTML, CSS, Bootstrap, Tailwind | **Tailwind** (what you use daily) |
| JavaScript, TypeScript | **TypeScript** |
| React, Next.js, React Query, react-hot-toast, … | **Next.js** (implies React) |

**Bad:** `HTML · CSS · Bootstrap · Tailwind · JS · TS · React · Next.js · React Query · …`

**Good:** `TypeScript · Next.js · PostgreSQL · Git`

If you would not use it on a project **this month**, leave it off. Same for "Currently learning" — one or two goals, not a hype list.

---

## Common mistakes

| **Mistake** | **Fix** |
| ----------- | ------- |
| Different username everywhere | Same handle across platforms |
| Profile README repo is private | Must be **public** |
| Repo name ≠ username | Must match exactly |
| 20+ redundant skills | Quality over quantity |
| README longer than sidebar | Trim content — pins should stay visible without long scrolling |
| Heavy animations / badge walls | Optional, but they bloat the page — projects matter more |
| Empty sidebar, README only | Fill **Edit profile** and pins too |
| Activity overview turned off | Enable it in **Contribution settings** — shows repos, orgs, and PR/issue/review split |
| Only commit counts, no OSS activity | Open issues, submit PRs, review others — not just local commits |
