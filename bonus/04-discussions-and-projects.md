# Bonus 4 — Discussions, Projects & Notifications

> **Discussions**, **Projects** boards, and **notifications** — community and planning tools beyond Issues and PRs.

**Prerequisite:** [Lesson 8](../lessons/08-open-source-workflows.md)

---

## Issues vs Discussions

| **Issues** | **Discussions** |
| ---------- | --------------- |
| Actionable task with a done state | Open-ended conversation |
| Bug fix, feature work | Ideas, Q&A, polls |

Needs a PR fix → **Issue**. Brainstorming → **Discussion**. Maintainers can convert one to the other.

Enable Discussions: Settings → General → Features → **Discussions**.

---

## Projects board

Kanban board for issues and PRs.

1. Repo → **Projects** → **New project** → **Board**
2. Columns: Todo → In progress → Done
3. Add issues from the issue sidebar or **+ Add item** on the board
4. Drag cards as work moves

---

## Notifications

**Watch** (top right of any repo):

| **Level** | **When to use** |
| --------- | --------------- |
| **Participating and @mentions** | Good default |
| **All Activity** | Only if you maintain the repo — very noisy otherwise |
| **Ignore** | Mute the repo |

Use `@username` sparingly to notify someone. Bell icon → mark threads **Done** when finished. Tune email in **Settings → Notifications**.

---

## Community tab

Shows whether a repo has README, LICENSE, CONTRIBUTING, CODE_OF_CONDUCT. Read the conduct rules before posting.
